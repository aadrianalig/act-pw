Sobre el curso

Una vez consolidada la estructura y la presentación visual, daremos el salto hacia la interactividad utilizando JavaScript, lo que nos permitirá modificar el DOM para cambiar lo que se ve sin tener que recargar la página. Esta etapa es fundamental para entender cómo funciona el frontend moderno y la experiencia de usuario antes de introducirnos a librerías avanzadas como React.

Hacia el final del curso, completaremos nuestra visión como futuros ingenieros de sistemas dominando el lado del backend, donde implementaremos el modelo de arquitectura cliente-servidor. Aprenderemos a construir nuestra propia lógica en el servidor utilizando Node.js con Express y nos conectaremos a bases de datos para guardar la información de forma persistente, logrando así el desarrollo de aplicaciones web completas.
